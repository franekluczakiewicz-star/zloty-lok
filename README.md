# Salon Fryzjerski Złoty Lok

Strona salonu Anny Ząbczyńskiej w Rudzie Śląskiej.

## Podgląd lokalny

Otwórz plik `index.html` w przeglądarce albo uruchom prosty serwer:

```bash
python3 -m http.server 8080
```

## GitHub Pages

Strona jest publikowana z gałęzi `main` (katalog główny repozytorium).
